	Updated notification link for missing module manager
	Added build files
		deploy.bat
		jenkins.txt

	Added code to RSTUtils.Utilities.Log to replace braces in strings with double braces, so that the formatting doesn't error.  Needed for people who decide to use braces in their directory names

	Moved Plugins/PluginData to root of mod dir

1.31.0.3
	Fixed problem in status window which causes huge FPS drop with a large number of kerbals.  On a 9850X3D system with 20 kerbals in freeze chambers, caused a 72% drop in FPS, from 180 down to 70
	Replaced obsolete call to KerbalPortraitGallery.ActiveCrew with Reflection code to get the protected list KerbalPortraitGallery.activeCrew (a bit of an optimization)
